# Развивайка · Teramont

Telegram Mini App с играми для логики, памяти и внимания. Открой бота, нажми «Играть» и выбери кампанию. Устанавливать отдельное приложение не нужно.

## Память разработки

[MEMORY.md](MEMORY.md) хранит историю запросов и решений из чата, текущее
состояние игр, результаты проверок, ограничения и планы игровой платформы.
Порядок чтения и дальнейшего обновления задан в [AGENTS.md](AGENTS.md).

## Игры и прогресс

Десять самостоятельных кампаний по 100 уровней: судоку, найди пары, логические задачи, числовые последовательности, пятнашки, матрица памяти, японский кроссворд, устный счёт, шифры и ребусы, цвет и внимание. Всего 1000 этапов, сложность постепенно растёт. Есть свободная игра.

- XP, уровень игрока, девять званий и 30 достижений.
- Серия ежедневной игры и рекорд серии; день считается по московскому времени.
- Отдельный прогресс каждой кампании, статистика и профиль Telegram.
- Серверная SQLite хранит результаты по Telegram-пользователю. API проверяет подпись initData, владельца игровой сессии и открытый уровень. Повтор сохранения результата не начисляет XP повторно.
- По одной незавершённой партии каждого типа сохраняется на устройстве. Telegram DeviceStorage используется на клиентах версии 9.0+, иначе localStorage. Результаты с неудавшейся отправкой можно синхронизировать повторно.
- В обычном браузере явно обозначен локальный профиль для просмотра интерфейса.

Игры реализованы в проекте, поля генерируются. Судоку и японские кроссворды проверяются генератором на единственность решения, пятнашки перемешиваются допустимыми ходами. API принимает факт завершения от клиента: полноценной защиты от подделки игровых результатов пока нет.

## Интерфейс

### Математический покер

В каталоге доступен техасский холдем один на один: с ботом или с другом.
Оригинальные 52 SVG-карты, зеркальные фигурные карты и узорная рубашка,
анимации раздачи, раскрытия и фишек; reduced motion учитывается.

- Стартовый стек 1000 виртуальных фишек, блайнды 10/20. Настоящие улицы,
  чек/колл/рейз/пас/олл-ин, кикеры, делёж банка и возврат непокрытой ставки.
- Подсказка показывает equity против случайной руки (400 симуляций), порог
  колла и EV без будущих ставок. Расчёт использует только свои и общие карты;
  бот также не читает карты игрока. Математика не гарантирует победу в раздаче.
- Одиночная игра доступна в браузере. Для мультиплеера оба игрока открывают
  Mini App из Telegram: один создаёт комнату, другой вводит шестизначный код.
  Обновление примерно каждые 1,5 секунды. Между раздачами нужны оба подтверждения.
- Авторитетное состояние и закрытые карты хранятся в SQLite; браузер сохраняет
  ссылку на стол и секретный токен одиночного режима. Комната хранится 72 часа
  после последнего изменения; затем можно убрать недоступное сохранение.
  Выход к играм сохраняет стол, «Завершить стол» закрывает его для обоих.
- Это отдельный тренировочный режим, без денежных ставок и начисления XP кампаний.

API: `/api/poker/solo`, `/rooms`, `/rooms/join`, `/rooms/{id}`,
`/rooms/{id}/action`, `/rooms/{id}/hint` (все пути после `/api/poker`).
Используется существующая БД `GAME_DB_PATH`; для изоляции можно задать
`POKER_DB_PATH`. Нужен один общий SQLite-файл для процессов API одного сервера.
Направление и проверка: [дизайн](design/poker-direction.md),
[результаты](design/poker-review.md).

### Шахматы с компьютером

В каталоге есть отдельные шахматы против Stockfish 19 Lite. Шесть сложностей:
начальный — Новичок, легко — Любитель, средне — Клубный игрок, сложно —
Эксперт, очень сложно — Мастер, ультрасложно — Гроссмейстер. Это названия
игровых режимов, а не измеренный рейтинг Elo. Сила задаётся настройками
движка, глубиной и временем расчёта; новичок дополнительно допускает
случайные легальные ходы.

Можно выбрать белые, чёрные или случайный цвет. Есть подсветка допустимых
ходов, история, отмена полного хода, переворот, превращение пешки, рокировка,
взятие на проходе, мат и ничьи. Партия без часов сохраняется на устройстве
по тому же Telegram-пользователю; шахматная статистика также локальная.
XP и достижения десяти кампаний относятся к головоломкам.

Правила — chess.js 1.4.0, движок — Stockfish.js 19.0.1 lite-single
в отдельном Web Worker. Движок загружается только при начале/продолжении
партии, около 1,9 МБ без сжатия (около 1,2 МБ с gzip); CDN во время игры не нужна.
Показывается процент загрузки. Публичные файлы библиотек кэшируются на неделю,
а API и остальные страницы сохраняют Cache-Control: no-store.
Все файлы, лицензии,
исходники движка и его оценочная сеть находятся в
`webapp/frontend/vendor/`. Обновлять без изменения версий:
`python deploy/fetch_chess_assets.py` (Python и Node.js).
Направление и наблюдения: [шахматы](design/chess-direction.md),
[проверка интерфейса](design/chess-review.md).

### Игротека

Светлая игротека с миниатюрами механик, фильтрами по навыкам, одним блоком
последней сохранённой партии и отдельным игровым экраном. В кампании главы
раскрываются по десять уровней, в профиле ближайшая награда показана перед
коллекцией. На компьютере навигация слева, на телефоне — снизу; во время партии
общая навигация скрыта. Направление: [дизайн](design/frontend-direction.md).
Браузерные наблюдения и ограничения: [проверка](design/frontend-review.md).
Для получения нового интерфейса закрой Mini App и открой её заново.

## Быстрый запуск на Windows

1. Скопируй `.env.example` в `.env` и задай `TG_BOT_TOKEN`.
2. Установи зависимости: `python -m pip install -r requirements.txt`.
3. Запусти `python run_local.py`. Нужен установленный OpenSSH (`ssh`).
4. Дождись запуска API, публичного HTTPS-туннеля localhost.run и бота. Открой бота и отправь `/start`.

`python run_local.py --status` показывает состояние; `python run_local.py --stop` останавливает процессы этого запуска. Логи и служебные файлы находятся в игнорируемом `runtime/`. Лаунчер восстанавливает дочерние процессы и обновляет кнопку бота при смене адреса туннеля. Туннель временный, зависит от сети и работающего компьютера. Для постоянного доступа используй сервер и свой HTTPS-домен: [развёртывание](deploy/DEPLOY.md).

Для отдельного просмотра интерфейса: `uvicorn webapp.backend.main:app --host 127.0.0.1 --port 8080`, затем `http://127.0.0.1:8080/`. Отдельный запуск бота: `python -m bots.razvivayka.main`; в `.env` должен быть доступный HTTPS-адрес `APP_URL`.

### Автоподъём туннеля и автозапуск Windows

`powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install_autostart.ps1` устанавливает задачу `TeramontGamesAutoStart` для текущего пользователя. API, туннель и бот запускаются скрыто при входе в Windows. Права администратора не запрашиваются; если Планировщик недоступен, создаётся ярлык в папке автозагрузки пользователя. Конфигурация записывается в `runtime/autostart.json`.

- SSH keepalive обнаруживает потерю соединения; завершившийся SSH запускается повторно с паузами от 2 до 30 секунд.
- Раз в 20 секунд проверяются локальный API и публичный HTTPS. После трёх сбоев публичного адреса при работающем API туннель пересоздаётся, даже если SSH-процесс не завершился.
- Если туннель не становится доступным за 60 секунд, запускается новая попытка.
- Новый адрес публикуется после успешного ответа API; бот обновляет общую кнопку, кнопки меню существующих чатов и последнее отслеживаемое сообщение запуска.
- Файловая блокировка предотвращает одновременный запуск нескольких экземпляров лаунчера. Фоновая оболочка повторяет запуск лаунчера через 30 секунд при его завершении с ошибкой.

Проверить состояние: `python run_local.py --status`; поля `tunnelStatus`, `reconnects`, `publicHealthFailures`, `lastPublicHealthAt`. Лог: `runtime/launcher.log`. Остановить текущий запуск: `python run_local.py --stop` — штатная остановка не вызывает повторного запуска до следующего входа в Windows или ручного старта задачи.

Удалить автозапуск: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install_autostart.ps1 -Remove`. Это не останавливает текущие игровые процессы. Для немедленного повторного запуска зарегистрированной задачи: `Start-ScheduledTask -TaskName TeramontGamesAutoStart`.

## Telegram

Команды: `/start`, `/play`, `/profile`, `/help`. При запуске бот обновляет команды и описание. При обращении пользователя удаляет постоянную клавиатуру, обновляет кнопку меню и последнее отслеживаемое сообщение запуска. Исторические inline-кнопки, идентификаторы сообщений которых неизвестны, Telegram API массово удалить не позволяет; при нажатии старого callback бот убирает его и показывает новую кнопку.

Mini App запрашивает fullscreen, отключает вертикальные свайпы и включает подтверждение закрытия на поддерживаемых клиентах. Жест по верхней панели контролирует Telegram, поэтому выход исключительно через «×» гарантировать нельзя. [Документация Telegram](https://core.telegram.org/bots/webapps).

## Структура и проверки

- `webapp/frontend/` — интерфейс, генераторы задач, сохранения устройства.
- `webapp/backend/` — API, проверка Telegram, профили и прогресс.
- `bots/razvivayka/` — бот и обновление кнопок запуска.
- `run_local.py` — локальный запуск и восстановление процессов.
- `docker-compose.yml` — API, бот и Nginx; SQLite хранится в томе `game_data`.
- `tests/puzzles.cjs` — генерация всех 1000 этапов, воспроизводимость и условия решаемости.
- `tests/test_progress.py` — профили, кампании, повтор сохранения, серии, миграция и подпись Telegram.

Проверки: `node tests/puzzles.cjs` и `python -m unittest discover -s tests -p test_progress.py -v`.


Проверка интерфейса через скилл Playwright (отдельная браузерная сессия, локальный профиль):

1. `npx --yes @playwright/cli -s=teramont open http://127.0.0.1:8080/ --browser=msedge`
2. `npx --yes @playwright/cli -s=teramont resize 390 844`
3. `npx --yes @playwright/cli -s=teramont run-code --filename=tests/ui-smoke.js`
4. `npx --yes @playwright/cli -s=teramont run-code --filename=tests/ui-recovery.js`

Эти сценарии используют собственный локальный профиль браузерной сессии; первый сбрасывает его перед прохождением десяти игр. Они не запускаются внутри Telegram. Скриншоты находятся в `output/playwright/`.
