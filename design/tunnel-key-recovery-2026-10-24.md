# Короткий срок адреса localhost.run · 24.10.2026

## Причина

Логи показали смену hostname на том же SSH-процессе. В анонимных сессиях
за24.10 интервалы между регистрациями нового имени составляли от5,3с до20мин.
К моменту проверки действующий SSH работал более40мин с `reconnects=0`.
Поэтому восстановление завершившегося процесса само по себе эту причину не
устраняло: короткоживущим был публичный адрес.

В команде лаунчера были жёстко заданы `nokey@localhost.run` и
`IdentityFile=none`. [Документация сервиса](https://localhost.run/docs/forever-free/)
описывает более долгий срок бесплатного адреса после входа и регистрации
SSH-ключа. Купленный домен для этого режима не требуется.

## Изменение

Пользователь выполнил вход в localhost.run; отдельный публичный ключ добавлен
в аккаунт. Лаунчер поддерживает `TUNNEL_SSH_KEY` и при его настройке подключается
как `tunnel@localhost.run` с указанной идентичностью. Приватный ключ находится
в игнорируемом `runtime/`, настройка — в приватном `.env`. Отсутствующий файл
останавливает запуск с ошибкой вместо незаметного перехода к `nokey`.
Статус содержит `tunnelAuth`, инструкции добавлены в README и `.env.example`.

## Проверено

- Незарегистрированный ключ был отклонён; после регистрации сервер прислал
  `v1.auth_publickey.accepted`, затем новый публичный адрес.
- Пробное подключение, запуск лаунчера и принудительное переподключение SSH
  получили один и тот же hostname. При последнем переподключении API и бот
  не перезапускались.
- В17:14:59 произошёл отдельный `Connection reset`. В17:15:10 новый SSH уже
  вернул тот же hostname и успешный HTTPS. Это сетевой перерыв примерно11с,
  поэтому результат не означает непрерывную доступность без единого обрыва.

  Сырые результаты остаются в игнорируемом `runtime/tunnel-key-soak.json`.
- Telegram API подтвердил актуальный адрес общей кнопки и3/3 сохранённых меню.
- Публичный браузер загрузил арену Люмена и лабораторию Нулевого образца.

## Границы

Это всё ещё бесплатный туннель с ограничением скорости и срока адреса. Бессрочная
доступность и физический Telegram WebView не подтверждены. Компьютер должен
работать и иметь сеть. При покупке домена потребуется стабильное размещение
или соответствующий тариф туннеля; сам домен не устраняет сетевые обрывы.
