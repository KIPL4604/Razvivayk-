# Инструменты дизайна Развивайки

Настройка выполнена 16.10.2026 по запросу пользователя. Это доступ к компонентам и документации для разработки. Решение о применении компонентов в коде принимается с учётом текущего HTML/CSS/JavaScript и выбранного игрового дизайна.

## Подключения Codex

| Инструмент | Подключение | Назначение |
|---|---|---|
| 21st.dev | Существующий MCP `21st`; поиск выполнен в текущей сессии | Поиск компонентов и тем, получение выбранного кода в пределах доступного тарифа |
| ArloUI | MCP `arloui`, пакет `@arloui/mcp@0.1.0` | Документация мобильных композиций, токены и компоненты React Native |
| HeroUI | MCP `heroui-react`, пакет `@heroui/react-mcp@1.1.2` | Документация, CSS, темы и исходники компонентов HeroUI React v3 |
| Astryx | MCP `astryx`, `https://astryx.atmeta.com/mcp` | Поиск компонентов, тем и документации Astryx |
| Iconimate | MCP `iconimate`, наш локальный адаптер к официальному реестру | Инструменты `iconimate_search` и `iconimate_get`: поиск и получение кода иконок |
| Posts.Design | `https://posts.design/`, доступ через веб-инструменты | Визуальные референсы для постов и анонсов |

ArloUI, HeroUI, Astryx и Iconimate успешно прошли MCP initialize и вернули tools/list. Через адаптер Iconimate выполнены поиск `star` и получение его исходного TSX с официального сайта. ArloUI и HeroUI установлены с фиксированными версиями в `D:/CodexTools/design-mcp` и запускаются напрямую через Node.js; это обходит повреждённый кэш npx на C:. Кэш установки находится в `D:/CodexTools/npm-cache`.

Новые MCP добавлены в пользовательскую конфигурацию штатной командой `codex mcp add`. Перед изменениями сохранена резервная копия конфигурации в пользовательской `.codex/backups/`. Для загрузки новых серверов в интерфейс инструментов может потребоваться перезапуск Codex. Наличие записи в конфигурации и успешная инициализация сервера не означают, что его инструменты уже загружены в текущий разговор.

## Адаптер Iconimate

Наш сервер расположен в `D:/CodexTools/design-mcp/iconimate-server.mjs`, копия исходника — `design/tooling/iconimate-server.mjs`. Это локальный адаптер, а не официальный MCP издателя. Зависимости закреплены: `@modelcontextprotocol/sdk@1.32.1`, `zod@3.25.76`. Сервер читает только официальный каталог Iconimate и компоненты с именами из него; не записывает файлы проекта и не выполняет полученный код.

Posts.Design остаётся веб-источником. Подтверждённое MCP-подключение для него не установлено.

## Работа с компонентами

- 21st.dev: сначала бесплатный поиск, затем получать код конкретного компонента. На момент настройки доступно два бесплатных получения кода; генерация 21st AI на текущем тарифе отключена. Перед будущим использованием проверять актуальные ограничения.
- HeroUI и Astryx — альтернативные системы компонентов. Не смешивать их оформление в одной игре без обоснования.
- ArloUI предоставляет React Native код: для браузерной Mini App использовать подходящие принципы и токены, а не импортировать нативные компоненты в DOM.
- Iconimate возвращает React/TSX и использует Motion. Для текущего фронтенда нужна адаптация либо отдельное решение о React. Проверенные адреса: `https://iconimate.app/r/bell.json`, `https://iconimate.app/r/star.json`. При переносе кода сохранять MIT-атрибуцию Iconimate и Phosphor и учитывать reduced motion.
- Posts.Design используется как источник визуального анализа; публикация постов или действия от имени пользователя не предполагаются.
