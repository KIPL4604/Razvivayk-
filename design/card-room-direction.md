# Карточная комната · направление 19.10.2026

Запрос пользователя: добавить Дурака и другие карточные игры, отдельную вкладку,
карты/анимации из MCP; все кнопки внутри игры в одной стилистике, полный экран.

Добавляются подкидной Дурак на двоих с ботом, Блэкджек с дилером и Косынка.
Существующий покер остаётся серверным solo/online и получает общую иммерсивную
оболочку. Новые игры одиночные, сохраняются на устройстве, без серверных XP.
Кампании, Люмен, шахматы, правила и сетевые контракты покера сохраняются.

Выбор: светлая библиотека Teramont + полноэкранная зелёная карточная комната.
Альтернатива — светлые плоские игровые поля — не соответствует просьбе о
погружении. В партии весь viewport занимает единое сукно: тёмный хвойный #143C36,
мягкая текстура, кремовая бумага #FFFDF5, латунь #CBA96B, читаемые светлые подписи.
Системная кириллица для управления, Georgia на индексах карт. Ритм8/12/16/24,
кнопки44px+, тонкие контуры. Отдельная белая панель управления под столом убирается.

Путь: вкладка «Карты» → выбор режима → партия на одном экране → результат/повтор.
Header содержит назад, имя, правила/меню и fullscreen. Соперник сверху, стол
посередине, рука и действия снизу. Большая рука Дурака разбивается на страницы
кнопками внутри поля; общий экран не прокручивается. Для Косынки семь столбцов
с адаптивным перекрытием; карта/назначение выбираются кликами, есть подсказка/undo.
Правила и математика покера — диалоги с внутренней прокруткой и focus management.
Светлая оболочка возвращается после выхода. Fullscreen: Telegram8.0+ и browser
Fullscreen API по жесту; swipes7.7+, safe areas; жесты системной панели не обещаны.

MCP реально использованы: 21st Tilt Flip Card id12635 и Card Hand Gallery id34856
(получен код), ArloUI motion foundation, Iconimate Arrows Out (геометрия/MIT).
В MCP поиска готовой French-suit колоды не найдено: используется существующая
авторская SVG-колода Teramont52, её детализированные двусторонние court cards.
React/Motion/GSAP не добавляются: vanilla-реализация геометрии веера, подъёма,
3D-переворота и перемещения через Web Animations API. Чужие demo-изображения и
React source не поставляются; provenance и лицензии сохраняются в отчёте/notices.
Reduced motion убирает перелёты/вращение, оставляет понятное изменение состояния.

Правила: [Дурак/Pagat](https://www.pagat.com/beating/podkidnoy_durak.html),
[Блэкджек/Bicycle](https://bicyclecards.com/how-to-play/blackjack/),
[Косынка/Bicycle](https://bicyclecards.com/how-to-play/klondike/).
Варианты явно подписаны: Дурак36/6карт/без переводов; Blackjack one deck/S17,
double/no split/insurance; Косынка draw-one/неограниченные пересдачи.
Состояния правил/результатов не заменяют реальные действия; auto-win нет.

Приёмка: движки и полные seeded партии, отрицательные ходы/сохранения,
четыре размера375/768/1440/1920 и две визуальные итерации; keyboard/touch,
reload/resume, fullscreen/scroll lock, скрытые карты отсутствуют в DOM,
реальные покерные REST/WS и регрессии остальных режимов. Физический Telegram
и мобильная длительная приёмка отдельно не считаются проверенными браузером.
