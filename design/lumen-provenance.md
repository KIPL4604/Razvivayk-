# Люмен · происхождение реализации

19.10.2026. Постановка пользователя: независимая игра в жанре survival с
автоатаками по принципу чистой комнаты. Функциональный brief описывает движение,
волны, сбор опыта, выбор усилений и ограниченный по времени забег.

Исходники, бинарники, спрайты, музыка, карты, тексты, UI и декомпиляция Vampire
Survivors не использовались и не исследовались при реализации. Нет заимствованных
репозиториев с клонами. Продукт называется «Люмен: последний маяк», имеет свой
ночной биосад, механических противников, разведчиков и световые устройства.

| Материал | Происхождение |
| --- | --- |
| Симуляция и баланс | Созданы в `js/lumen/engine.mjs` по функциональному brief; без DOM, сети и стороннего кода; чистые правила волн/XP — progression.mjs |
| Следопыт, базовый враг, растения, пол, маяк | Оригинальные imagegen PNG; исходники, prompts и нормализация в `design/lumen-pixel/`, runtime в `assets/lumen/` |
| Панцирный и летающий враги | Оригинальные imagegen sheets30кадров,20.10.2026, source briefs в lumen-pixel/motion-sources.md |
| Хранитель и guardian | Сохранённая прежняя Canvas-графика в `js/lumen/legacy-art.mjs` |
| Миниатюра каталога | PNG-композиция из собственных атласов, `assets/lumen/cover.png` |
| Звуки | Синтез Web Audio: короткие синусоидальные сигналы, `js/lumen/game.mjs`; аудиофайлы не поставляются |
| Названия, описание, правила, интерфейс | Написаны для этого режима; интерфейс DOM/CSS в существующем Teramont |
| Шрифт игрового HUD | Tiny5, локальный статический Latin/Cyrillic subset; оригинал сохранён, SIL OFL 1.1 в `assets/lumen/fonts/OFL.txt` |
| Runtime | Стандартные Canvas 2D, Web Audio, Pointer Events и Fullscreen API; новых сторонних пакетов нет |
| Telegram SDK | Уже существующий SDK всей платформы; API fullscreen/swipes сверены с официальной документацией |

Разделение работ: координатор сформировал самостоятельный игровой brief,
интерфейс и графику; отдельный исполнитель написал чистую симуляцию и тесты.
Оба работали по указанному brief, без доступа к исходной реализации референса.
Это описание фактического процесса, не сертификат формальной двухкомандной
clean-room процедуры и не юридическое заключение о правах во всех странах.

Общий принцип отделения игровой идеи и метода от конкретного защищённого
выражения описан [US Copyright Office](https://www.copyright.gov/help/faq/faq-protect.html).
Проверка товарных знаков/патентов и отдельная правовая экспертиза не проводились;
не заявлять абсолютную гарантию юридической чистоты.
