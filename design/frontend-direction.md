# Teramont · светлая игротека

Выбранное направление: одобренный светлый референс из `design-direction.png`. Спокойный фон #F5F7FB, белые поля, основной текст #20263D, синий #3567DC. Системный шрифт с кириллицей; выразительные заголовки, табличные цифры. Ритм 4/8/12/16/24/32 px. Цветовые пятна только у собственных SVG-миниатюр механик.

Главный путь: игра → текущий этап кампании → партия → результат → следующий этап. Каталог показывает игры сразу; продолжение появляется только для реальной незавершённой партии. Кампания раскрывает текущую главу из десяти; профиль выводит ближайшую награду перед коллекцией и подробностями кампаний. На широком экране навигация слева; в мобильном Telegram снизу. В партии общая шапка и навигация скрыты, правила раскрываются отдельно.

Референсы: Sudoku.com — размер поля; Lumosity — узнаваемые миниатюры механик; NYT Games — самостоятельная геометрия игр. Чужие изображения в продукт не переносятся. Из MCP: ArloUI — композиция; Astryx ClickableCard — одна осмысленная цель карточки и состояния нажатия; HeroUI ProgressBar/Disclosure/Tabs — подписанный прогресс и доступное раскрытие; 21st.dev — просмотр вариантов прогресса (ретро и dashboard-композиции не выбраны); Iconimate Star — адаптация SVG и короткого движения для наград с reduced motion. React-библиотеки не устанавливаются в существующий vanilla JS проект.

Сохраняются API, проверка Telegram, сохранения, очередь результатов, десять кампаний, 1000 этапов, XP, звания и достижения. Все счётчики берутся из профиля. Предпросмотр браузера явно локальный. Проверка результата: реальные браузерные сценарии и две итерации скриншотов на 375/768/1440/1920 CSS px. Автоматизированные тесты в задаче не запускаются без запроса пользователя.
