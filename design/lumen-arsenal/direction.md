# Люмен · герои, арсенал и сундуки / 20.10.2026

Пользователь уточнил: нынешняя цветовая гамма — стилистика карты, не всей игры.
Поручены множество героев с родным оружием, больше приятных PNG-значков/эффектов,
мобы/боссы, сундуки с монетами для покупки героев и возможным улучшением оружия.
Пример обязательной прогрессии: один вращающийся снаряд, через два улучшения два.

Первое расширение:6героев,8оружий,6обычных видов существ и3разных стража.
Сохраняются перспектива3/4,чёткие пиксели,пять6-кадровых анимаций,48px персонажи.
Боссы крупнее и подробнее. Цвета/палитры задаются отдельно для каждого существа
и карты; новые герои не перекрашиваются в зелёный биосада. Общий контур/свет/
масштаб объединяют разные образы. Герои/существа — настоящие PNG из imagegen
whole sheets, исходники и prompt log сохраняются. Ни CSS-тела, ни emoji.

Следопыт/разряд и Хранитель/волна доступны изначально; Алхимик/колбы120,
Охотница/лёд200, Дуэлянт/клинки320, Грозовик/цепная молния450 монет.
Ещё два оружия — возвратные секиры и терновые ловушки. По5стадий, число
снарядов/клинков/волн растёт на стадияхIII/V. В забеге до6видов оружия;
краткое описание следующей стадии видно перед выбором. Цвет дублируется формой.

Главный путь: выбрать/купить героя → бой с родным оружием → усиления → победить
элиту/стража → подобрать сундук → монеты/возможное усиление → новый герой.
Монеты только игровые, локальные, без реальных покупок/кампанийногоXP. Кошелёк
и забег сохраняются вместе; повторный resume не начисляет награду заново.
Сундук открывается при подходе, короткое сообщение не перекрывает бой.

UI: подробный квадратный Tektur, предметные PNG-иконки, цвет персонажа как
локальный акцент. Выбор героев — горизонтальная полоса с крупным портретом и
стартовым оружием; магазин сообщает цену/баланс/причину недоступности.
Пауза/фокус/сенсорное управление/nearest и камера сохраняются. Проверка4ширин,
две визуальные итерации, полная симуляция, миграция старых saves, сохранение
кошелька, chest/purchase idempotency, пределы объектов и стоимость кадра.
