# Приёмка игровых меню — 02.11.2026

## Что изменилось

Предыдущий атлас Люмена и терминальное досье образца пользователь отклонил как слишком похожие на сайт. Теперь обе игры открываются центральным титульным меню. Люмен: Играть / Магазин / Настройки; арсенал и прокачка — вторичные действия. Образец: Играть или Продолжить / Настройки / Управление. Магазин образца не выдумывался.

За окнами воспроизводится запись собственного игрового рендера: два ролика около 15 секунд, каждый меньше 3 МБ. Пауза при уходе, скрытии документа, ручном отключении и reduced motion. Постеры доступны без воспроизведения. Локальный демонстрационный fixture изолирован от прогресса игрока; описание в media.md.

Хаб: боковая навигация desktop, нижняя mobile, поиск по реальным играм, фильтры, журнал из трёх статей, профиль и настройки. Общие монохромные темы сохранены между перезагрузками. Четыре юридические ссылки находятся внизу профиля, отдельной юридической вкладки нет. Документы — черновики без выдуманных реквизитов, контактов, юрисдикции и сроков хранения.

## Проверка Unslop и MCP

Пройденные визуальные проходы: композиция (главное действие в центре игры), типографика (системная, ограниченные размеры), цвет (нейтральные поверхности / цвет только в игровом контенте), иерархия (основные и вторичные действия), отступы (4 px), плотность (окна ограничены 78–80% высоты), оформление (тонкие границы, небольшие радиусы), изображения (собственная запись вместо декоративной hero-обложки), движение (короткий шаговый переход, без циклических UI-эффектов).

Реально вызваны ArloUI MCP Motion / Spacing / Sheet и Iconimate MCP search/get Arrow Right 7453ab9b2fcf. По этим материалам уточнены header/body/footer окна, 44–48 px hit targets, направление перехода, 130 мс press feedback и однократное движение стрелок. React/Motion/React Native не добавлены. MIT notice сохранён в THIRD_PARTY_NOTICES.md.

## Два визуальных цикла

Браузер: Headless Edge 156, localhost:8080, изолированные контексты без настоящего Telegram initData. Ширины 375 / 768 / 1440 / 1920 CSS px. Снимки локально: output/playwright/game-menus-20261102/ (игнорируется Git).

Первый личный просмотр выявил: старый импорт lumen-menu.css перекрывал новые стили; кнопки сжимались, фон окон менялся; портреты захватывали несколько кадров sprite sheet; заголовок настроек образца наследовал гигантский размер. Импорт удалён, геометрия и размер кадра исправлены, заголовки ограничены. Во втором просмотре исправлены контраст справки в светлой теме, лишние внутренние поля окна, подсветка выбранного героя и подпись паузы фона. Итоговые изображения просмотрены лично, включая hub-dark-768-i2, lumen-1920-i2, lumen-shop-dark-1440-final, профиль с юридическими ссылками и mobile справку.
