# Исправление навигации и ввода

Продукт: библиотека игр и самостоятельные игры. Характер: спокойный, отзывчивый, понятный. Сохраняются монохромные темы и авторская графика. Богатый контент — обложки и игровой фон; навигация остаётся простой.

Нижняя панель: Игры / Карты / Профиль / Настройки, настоящие SVG вместо текстовых символов. Статьи убираются из отдельной страницы и переносятся в справку по знаку вопроса вверху. Профиль показывает фото Telegram, когда SDK предоставляет photo_url, с резервным инициалом при отсутствии или ошибке загрузки.

Свайп — движение страницы за пальцем с плавным завершением или возвратом. Порог — заметная часть ширины, короткие движения возвращаются. Направление определяется до изменения страницы, исходное содержимое остаётся на экране до завершения жеста. Синтетический click после перетаскивания подавляется на уровне документа даже при замене DOM. Категории, горизонтальные списки, поля и элементы игрового управления имеют собственную область жеста, выбранную по началу касания; уход пальца из этой области не передаёт жест навигации.

MCP: ArloUI Fluidity для непрерывности и направления; Iconimate User / Gear для SVG, исходный значок четырёх плиток и карточек сохранён. Последнее уточнение пользователя о плавности заменяет прежние покадровые steps. Две визуальные проверки 375/768/1440/1920, реальные touch c отменой, свайпами по кнопкам/категориям и длинным спискам; клавиатура/reduced motion, фото с ошибкой. Бот проверяется по реальному polling, а не только getMe.
