# Статичные фоны игрового меню

Заменить видеозаписи реальными неподвижными кадрами карты. Сохранить центральные
кнопки, небольшие окна, текущие шрифты и две темы. Фон не движется и не требует
управления воспроизведением; экран подготовки больше не скачивает видео.

Люмен: заранее снятые кадры оригинального renderer без HUD, выбран только
последний открытый мир из доступного меню (Биосад → Карьер → Замок). Выбор карты
для нового забега не меняет этот фон. Декодировать выбранный кадр перед меню.
Не скачивать кадры закрытых миров. Сохранить подготовку графики перед игрой.

Образец: один снимок оригинального renderer по последнему доступному сектору
валидного run/checkpoint; при завершённом побеге — финальный сектор. Снимок
строится из уже подготовленных игровых ресурсов, без загрузки отдельного видео.
Снимок не меняет прогресс, не запускает simulation и сохраняется между окнами.

Проверить новые/пройденные/некорректные сохранения, отсутствие запросов к видео,
четыре ширины и обе темы; визуально осмотреть два цикла. Игровые механики и
форматы сохранений не менять. Design Workbench + Game UI Frontend.
