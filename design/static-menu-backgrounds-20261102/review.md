# Статичный фон последней доступной карты

Видео удалено из меню Люмена и Образца вместе с загрузкой и управлением
воспроизведением. Отдельные окна и центральные действия сохранены. Глобальная
настройка теперь управляет откликами интерфейса и так и называется; фоны всегда
неподвижны. Подготовка игровых ресурсов перед вступлением и игровым canvas сохранена.

Люмен использует реальные кадры своего renderer без HUD: Биосад 157774 байта,
Лунный карьер 137132, Замок 236588. Сборка — scripts/capture-lumen-menu-stills.mjs.
Порядок доступности совпадает с действующим меню: garden → quarry → castle.
Скрытый legacy crater не подменяет замок. Выбранная карта забега не влияет на
фон. Загружается только кадр последнего доступного мира, по SHA256 через прежний
публичный кэш. После открытия нового мира фон подготавливается и при прямом
возврате через controller.setup. Просроченное ожидание фона отменяется при уходе.
Старые видеоролики из CacheStorage удаляются; файлы прежних записей остаются
исходными материалами и больше не запрашиваются приложением.

Образец делает один снимок уже готового renderer по последнему доступному сектору
валидных run/checkpoint; для завершённого побега — сектор 08/Топь. Снимок хранится
в img как data URL и меняется только при новом входе/изменении размеров или
доступного сектора. Камера renderer восстанавливается после снимка, а кэш комнаты
инвалидируется для следующего игрового кадра. Исходное сохранение не меняется,
simulation не запускается. Повторные окна используют тот же кадр.

Проверено:

- Новый статический сценарий: 35 browser checks, включая разные/невалидные
  сохранения, открытие нового мира, независимость от выбранного garden,
  последнюю комнату/победу, неизменность save и отсутствие запросов к видео.
- Обновлённые regression: 28 loading/cache/failure, 22 navigation, 13 touch,
  34 social/navigation/loading — всего132 browser checks, 0 JS errors.
- 11 Python art tests. Проверен синтаксис изменённых JS/ES modules; frontend
  сборки здесь нет (vanilla JS). Полные боевые прогоны не требовались и не запускались.
- Лично просмотрены два цикла снимков при375/768/1440/1920, в обеих темах,
  главное меню и окно настроек. После первого цикла убрана полоска здоровья с
  кадров Люмена через штатный preview-режим renderer.
- При отказе фонового изображения меню не показывается частично; доступны
  повтор и возврат. Повторная загрузка мира/меню использует прежний versioned cache.
  Reduced motion и клавиатура проверены существующими сценариями.

Снимки QA и тестовые БД — только ignored output/static-menu-backgrounds и
output/hub-social-loading. Три WebP карты — собственные игровые runtime assets,
без личных данных. Физические клиенты Telegram не проверены. Backend/API,
бот и туннель для этой frontend-правки перезапускать не требуется.
