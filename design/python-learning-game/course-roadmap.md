# Программа «Питон-станции»

## На чём строится курс

- **Содержание — Python for Everybody.** Основа — лекции Charles R. Severance. Из второй лекции берём связку «значение и тип → преобразование → вычисление», из следующих — условия, циклы, функции, текст, коллекции и прикладные главы. Для материалов, явно выпущенных под CC BY 4.0, указываем автора, исходник, лицензию и адаптацию. Сюжеты, задания и интерфейс станции описаны на русском. [Лекции PY4E](https://github.com/csev/py4e/tree/master/lectures3) · [Пример лицензированных слайдов](https://umsi.py4e.com/lectures3/Pythonlearn-02-Expressions.pdf) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- **Практика — Helsinki Python MOOC.** Маленькое объяснение переходит в работу с кодом. В серии меняются действия ученика: предсказать вывод, исправить строку, написать решение, применить несколько знакомых приёмов. [Образец главы Helsinki](https://programming-26.mooc.fi/part-1/4-arithmetic-operations/)
- **Пошаговый проект — freeCodeCamp.** Ученик несколько раз дополняет одну программу. Сначала видит результат небольшого действия, потом объединяет шаги и получает проект, который можно сохранить. [Программа Python v9](https://github.com/freeCodeCamp/freeCodeCamp/blob/main/curriculum/structure/superblocks/python-v9.json) · [Первый шаг мастерской](https://github.com/freeCodeCamp/freeCodeCamp/blob/main/curriculum/challenges/english/blocks/workshop-report-card-printer/69461e4f98594012939bc1c6.md)
- **Проверка — Exercism.** Для задания задаём пример и дополнительные входы. Проверяем то, ради чего написан код: значение и тип переменной, вывод, возвращаемое значение или ожидаемую ошибку. При несовпадении называем конкретный случай. Сохраняем возможность решать задачу разными способами. [Пример тестов Exercism](https://github.com/exercism/python/blob/main/exercises/concept/ghost-gobble-arcade-game/arcade_game_test.py)

Привязка к лекциям задаёт фактическое содержание. Например, из главы PY4E об выражениях берём зависимость результата от типа входных данных, порядок операций, обычное и целочисленное деление. Пример с расчётом по двум величинам переносим в грузовой отсек станции. При проверке примеров используем семантику Python, включая `10 // 2 == 5` с типом `int` и преобразование дробных чисел к `int` в сторону нуля. [Выражения PY4E](https://umsi.py4e.com/lectures3/Pythonlearn-02-Expressions.pdf) · [Операторы Python](https://docs.python.org/3/reference/expressions.html#binary-arithmetic-operations) · [Функция int](https://docs.python.org/3/builtins/functions.html#int)

## Порядок глав

| № | Глава | Что осваиваем | Что получилось у ученика |
| --- | --- | --- | --- |
| 0 | Первый вывод | Запуск, текст, `print()` | Сообщение станции. Уже доступно. |
| 1 | Переменные | Имя, присваивание, чтение, обновление, простые вычисления | Список покупок с суммой и сдачей. Уже доступны 20 этапов. |
| 2 | Типы и преобразования | `int`, `float`, `str`, преобразование строки, различие между числом и его записью | Отчёт о весе груза по текстовым данным. |
| 3 | Арифметические операторы | Знакомые `+`, `-`, `*`, новые `/`, `//`, `%`, `**`, скобки и приоритет, `round()` для вывода | Рассчитать число полных контейнеров и остаток деталей. |
| 4 | Сравнения и логика | `==`, `!=`, `<`, `<=`, `>`, `>=`, `True`, `False`, затем `and`, `or`, `not` | Проверку допуска по заряду и наличию пропуска. |
| 5 | Условия | `if`, `elif`, `else`, отступы, порядок проверок | Контроль шлюза с тремя исходами. |
| 6 | Циклы | `for` с `range()`, накопление суммы, `while`, остановка и `break` | Журнал зарядки с шагами до нужного уровня. |
| 7 | Строки | Индексы, срезы, `strip()`, `lower()`, f-строки | Обработчик команд с пробелами и разным регистром. |
| 8 | Коллекции | Списки и перебор, `split()` / `join()`, словари, затем кортежи и множества | Инвентарь с остатками деталей и уникальными пропусками. |
| 9 | Функции и модули | `def`, аргументы, `return`, локальные имена, несколько вызовов и простой `import` своего файла | Один расчёт груза для разных отсеков. |
| 10 | Пользовательский ввод, ошибки и тесты | `input()` в консольной программе, traceback, `try` / `except ValueError`, простые проверки результата | Калькулятор, который обрабатывает пустой ввод и неверный формат. |
| 11 | Файлы и данные | `with open()`, пути, текст, CSV и JSON | Сохранение журнала станции и восстановление данных при запуске. |
| 12 | Первый графический интерфейс | Поле, кнопка, текст результата, обработчик события, простая компоновка на `tkinter` | Окно «Пульт груза»: ввести данные, нажать кнопку, получить вес или ошибку. |
| 13 | Классы и объекты | `class`, `self`, `__init__`, атрибуты, методы, композиция | Несколько отсеков со своим состоянием. |
| 14 | Базы данных | Таблицы, ключи, чтение и запись в SQLite, параметризованные запросы | Журнал груза с поиском по отсеку. |
| 15 | HTTP, API и боты | Запрос и ответ, JSON, обработка ошибок сети, команды и сообщения | Бот, который принимает данные, вызывает расчёт и выдаёт сводку. |

Главы 2–15 запланированы. Дробь и преобразование идут раньше полноценного разбора арифметики, чтобы связь типа и операции уже была знакома при введении деления. Сравнения и ветвление идут отдельными главами: сначала получить `True` или `False`, потом решить, какое действие выполнить. Сначала `for` работает на знакомых числах через `range()`, а в коллекциях тот же цикл применяется к списку.

## Следующая глава по этапам

| Этап | Действие ученика | Что возвращается из прошлых задач |
| --- | --- | --- |
| 1. Число и его запись | Определить результат `12 + 3` и `"12" + "3"`. Сохранить полученное показание под заданным именем. | Кавычки, присваивание. |
| 2. Текст от датчика | Преобразовать меняющееся показание `raw_count` через `int()` и вывести количество. | Чтение переменной через `print()`. |
| 3. Сверка запаса | Сохранить текстовое показание как число, прибавить две запасные детали, вывести итог. | Чтение, присваивание, сложение, преобразование из этапа 2. |
| 4. Подпись для табло | Преобразовать число обратно в текст через `str()` и добавить подпись. | Строковые кавычки и соединение строк. |
| 5. Дробное показание | Прочитать вес из текста через `float()` и сохранить его для расчёта. | Взять данные из переменной, сохранить и вывести. |
| 6. Целая часть | Предсказать результат `int()` для положительной и отрицательной дроби, затем проверить. | Разница между исходным значением и результатом преобразования. |
| 7. Починка записи | Найти причину ошибки в программе, где к числу прибавляют текстовое показание. Исправить код и получить сумму. | Преобразование из этапа 2 и счёт из главы «Переменные». |
| 8. Проект «Грузовой отсек» | Собрать одну программу за четыре шага. На входе тексты с весом коробки и количеством. На выходе общий вес груза. | `int()`, `float()`, присваивание, выражение и вывод. |

Проект начинается с целого количества коробок. На втором шаге появляется дробный вес одной коробки. На третьем вычисляется общий вес, на четвёртом программа выводит результат в понятном для оператора виде. Следом ученик меняет исходные данные и запускает ту же программу.

Для этапа 3 пример `raw_count = "12"` должен дать числовой запас 14 и вывод `14`. Дополнительные случаи с текстами `"27"` и `"0"` должны дать 29 и 2. Так и фиксированный ответ, и соединение строк приводят к ошибке проверки. В этапе 8 учитываем правильное преобразование каждого поля и результат умножения. В главе про сравнения этот результат вновь пригодится, чтобы узнать, можно ли отправить груз.

## От табло к своему окну

На ранних этапах визуальный результат показывает существующая 3D-станция. В главе 12 ученик сам делает окно: вводит два значения, вызывает уже знакомую функцию нажатием кнопки и отображает ответ. Обработчик использует опыт главы 10, чтобы показать понятное сообщение при неверном вводе. Для первого окна достаточно функций. Классы позже пригодятся при работе с несколькими объектами станции.

`tkinter` предназначен для настольных окон. Для проверки этой ветки нужен локальный Python с Tcl/Tk. Запуск такого окна внутри Mini App потребовал бы отдельной среды. Текущая учебная консоль умеет целые числа, строки и ограниченный набор выражений. Для главы 2 понадобится поддержать преобразования и различать `int` и `float` при проверке, в том числе при равном числовом значении `3` и `3.0`. [Документация tkinter](https://docs.python.org/3/library/tkinter.html) · [Текущая консоль](../../webapp/frontend/js/python-station/console.mjs) · [Сценарий действующей главы](learning-flow.md)

Дальнейшие ветки после основ могут опираться на этот маршрут. Для игр — координаты, события и состояние. Для аналитики — таблицы, файлы и визуализация. Для веб-разработки — HTTP, API и хранение данных.
