# Как писать уроки

## Объяснение на одном экране

1. Начать с ситуации. «Робот проехал коридор и потратил 4 единицы заряда».
2. Предложить предсказуемый пример. «Было 12, потратили 4, осталось 8».
3. Назвать понятие. «Чтобы сохранить новое число под тем же именем, обновляем значение переменной».
4. Показать код и связать строки с результатом. Сначала Python вычисляет правую часть `energy - 4`, затем сохраняет результат под именем `energy`.
5. Дать короткое действие с другими числами. Игрок дополняет код, проверяет его и видит, как меняется заряд.

Объяснять только новые символы на текущем шаге. Если показан `print()`, достаточно сказать, что он показывает значение на экране. Аргументы, функции и возвращаемые значения можно назвать позже, когда они понадобятся. Игровую реакцию дублировать текстом, чтобы без звука, цвета или анимации было видно, что произошло.

## Типы заданий

| Формат | Для чего | Пример |
|---|---|---|
| Предсказать вывод | Проверить, как ученик читает программу | Выбрать, появится ли `9`, `energy` или `8` после `energy = 9` и `print(energy)` |
| Заполнить пропуск | Применить один новый элемент | Вставить `=` между именем и значением |
| Собрать строки по порядку | Увидеть, как одно действие зависит от другого | Сохранить заряд, уменьшить его, вывести результат |
| Исправить ошибку | Научиться замечать причину | Убрать кавычки вокруг имени, чтобы увидеть число в переменной |
| Написать короткое решение | Проверить самостоятельный перенос навыка | Получить итоговый заряд для новых чисел |

## Обратная связь и повтор

- Подтверждать, какое действие сработало. «Робот передал число из переменной. Заряд на экране — 9».
- При ошибке описывать то, что сделал код, и давать один следующий шаг. «На экране появилось слово `energy`. Убери кавычки, чтобы Python прочитал значение переменной».
- Первая подсказка напоминает смысл действия, вторая показывает заготовку или похожий пример. После разбора можно дать такую же задачу с другими данными.
- Для выбора ответа сравнивать вариант, для микроупражнений на синтаксис проверять конкретную команду, для открытых задач сравнивать результат на разных входах. Если задание учит обновлять переменную, проверять её итоговое значение вместе с выводом.
- Старые задания возвращаются в новых главах с новыми данными. Неверный ответ открывает повторную попытку на той же карточке.

## Что передавать в разработку

У каждой карточки есть цель, условие, исходный код или варианты, действие игрока, ожидаемый результат, объяснение ошибки и две подсказки. У практической миссии также есть контрольные случаи, чтобы проверка засчитывала разные корректные решения. Разделы «Проверка» в сценариях адресованы разработчику. Игрок получает подсказки и результат по мере прохождения.
