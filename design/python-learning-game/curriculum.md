# Программа обучения Python

Курс начинается с первого вывода на экран. Каждая глава даёт станции новую возможность и заканчивается миссией, которая связывает её с уже знакомым кодом. Порядок глав опирается на [курс Mimo](https://mimo.org/courses/learn-python), а внутри глав темы и задачи подобраны под сюжет станции.

| Глава | Порядок микроуроков | Миссия | Что игрок умеет после миссии |
|---|---|---|---|
| 1. Запуск робота | Вывод текста и чисел → создание переменной → чтение переменной → вычисление → обновление значения | Посчитать заряд после поездки к маяку | Сохранить данные, изменить их и показать результат в консоли |
| 2. Датчики и сравнения | Число и строка → `True` и `False` → `==` и `!=` → `>`, `<`, `>=`, `<=` | Проверить, хватает ли ровно 8 единиц заряда для выезда | Записать результат сравнения в переменную и объяснить, почему на границе нужен `>=` |
| 3. Решения робота | `if` и отступы → `else` → `elif` → объединение условий через `and` и `or` | Открыть шлюз, запросить пропуск или отправить робота на зарядку | Описать разные реакции на разные данные |
| 4. Повторяющиеся действия | `for` с `range()` → счётчик → `while` и изменение условия | Зарядить робота до заданного уровня и записать каждый шаг | Выбрать цикл с известным числом шагов или с условием остановки |
| 5. Списки | Создание списка → индекс с нуля → изменение элемента → перебор списка | Вывести инструменты из рюкзака и заменить сломанный | Хранить и перебирать последовательность значений |
| 6. Операции со списками | `append()` → `remove()` → `len()` → сортировка | Собрать набор деталей по журналу поступлений | Обновлять состав списка и проверять, сколько элементов осталось |
| 7. Операции со строками | `strip()` → регистр → `split()` → сборка отчёта с f-строкой | Привести команды операторов к одному формату | Нормализовать текст и собирать понятный вывод |
| 8. Функции | `def` и вызов → параметры → `return` → несколько вызовов с разными данными | Посчитать остаток заряда для двух маршрутов одной функцией | Возвращать результат функции и использовать его дальше |
| 9. Кортежи, словари и множества | Кортеж координат → словарь и ключи → изменение значений → уникальные элементы множества | Собрать склад с координатами, остатками деталей и уникальными пропусками | Выбирать структуру по тому, как нужно читать данные |
| 10. Списковые включения | Перебор с `append()` → компактная запись → фильтрация условием | Собрать список маяков с зарядом выше порога | Преобразовывать и фильтровать списки короткой читаемой записью |
| 11. Классы | Объект и класс → `__init__` → атрибуты и `self` → два экземпляра | Создать двух роботов с разными именами и зарядом | Создавать объекты, у которых свои данные |
| 12. Объектно-ориентированное программирование | Методы объектов → изменение состояния → взаимодействие объектов | Зарядная станция пополняет заряд только выбранного робота | Распределить данные и действия между объектами |
| 13. Модули | `import` → вызов из модуля → импорт собственной функции из файла | Вынести расчёты маршрута из управляющей программы | Разделять код по назначению и переиспользовать его |
| 14. Ошибки и исключения | Чтение сообщения об ошибке → `int()` и `ValueError` → `try` / `except` | Обработать испорченное показание и выдать понятное сообщение | Найти причину ошибки и продолжить работу при ожидаемом сбое |

## Как растёт самостоятельность

- В начале темы игрок меняет один фрагмент готового кода и сразу видит результат.
- Следующее упражнение проверяет ту же идею на других данных. Пример остаётся доступен через подсказку.
- Миссия главы даёт задачу и данные, а игрок сам собирает решение из знакомых команд.
- В начале новой главы короткое упражнение возвращает навык из предыдущей. Например, перед `if` игрок сначала предсказывает результат сравнения, затем использует его для открытия шлюза.

Финальное задание курса — написать программу для выезда робота. Она получает данные о нескольких маршрутах из состояния игры, выбирает доступный, показывает остаток заряда и объясняет, если данных недостаточно или они ошибочны. Разные входные данные проверяют, что программа работает за пределами примера.
