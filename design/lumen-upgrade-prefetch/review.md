# Люмен · фоновые иконки следующего уровня

29.10.2026. [Контракт](direction.md), [иконки и контрольные суммы](icons.json).

## Поведение

При создании забега и сразу после выбора улучшения симуляция фиксирует
`nextUpgrade`: целевой уровень, подпись арсенала, до трёх предложений.
`upcomingUpgrade()` читает его без изменений состояния. На повышении
показываются обещанные оружия. UI не бросает случайные числа и не влияет
на RNG врагов. Подготовка использует отдельную копию текущего RNG;
при фактическом повышении сохранено прежнее продвижение боевого потока.

Старый runv11 без плана получает его при restore; уже открытый выбор
сохраняется. Новые поля проверяются/копируются. Если сундук изменил стадии,
план учитывает новый арсенал и исключает завершённые стадии. Опасное HP
может заменить вспомогательный вариант лечением, не обещанное оружие.
Все условия редкости/4оружий/5артефактов/слияний/максимальных стадий сохранены.

## Загрузка

24ячейки из исходных weapons/expedition/expansion-items извлечены в
самостоятельные48×48losslessWebP, всего18688байт, максимум1156байт/иконку.
Проверено точное совпадение RGBA с исходной ячейкой. Генератор:
`python design/lumen-upgrade-prefetch/build_icons.py`; данные для клиента:
`webapp/frontend/js/lumen/weapon-icon-data.mjs`.

`weapon-icons.mjs` запрашивает только оружия следующего набора; видимые
предметы меню/арсенала/HUD запрашиваются по мере появления. Закрытый
справочник рецептов не вызывает запросов. Два параллельных fetch с
priority=low, декодирование, дедупликация, переиспользование blobURL через
CSSvariables при серверном no-store. Кэш ограничен24элементами/страницу;
удалённые DOM-наблюдения освобождаются. Ошибка не останавливает игру:
вместо картинки нейтральный знак, текст и выбор рабочие, фоновые повторы
с паузой30с; реальный показ может повторить сразу. Таймаут12с.

Общий лист weapons исключён из обязательного decode выбранного мира;
expedition добавлен в зависимости снарядов chakram/spear/sunrise. Реальный
prepared checkpoint механиста подтвердил отрисовку chakram безJSerrors.
Боевые анимации и эффекты остаются в общих атласах, основной pack/manifest
не перепакован. Поэтому это оптимизация отдельных иконок, а не обещание
устранить все байты других оружий из общих боевых текстур. При мгновенных
повышениях подряд или плохой сети остаётся рабочее нейтральное изображение.
Новый UI не ожидает завершения предзагрузки.
