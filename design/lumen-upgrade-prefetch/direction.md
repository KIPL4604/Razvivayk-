# Люмен · заранее подготовленные улучшения

Пользователь: пока идёт бой, подгружать изображения только тех оружий,
которые появятся в следующем выборе. После выбора на уровне N заранее
определить набор для N+1. Не загружать весь арсенал ради трёх карточек.

Следующий набор определяет симуляция при начале забега/после выбора.
Он хранится в nextUpgrade, читается загрузчиком без расходования боевого
RNG. На повышении используются те же оружия. Редкости, четыре оружия,
пять артефактов, максимальные стадии и условия слияния сохраняются.
Сундук, изменивший арсенал, обновляет ещё не показанный план; лечение при
опасном HP может заменить только вспомогательный вариант, не обещанное
оружие. Сохранения v11 без плана продолжают работать; новый план явно
проверяется и копируется при восстановлении, старый выбор не заменяется.

24иконки оружия извлекаются из имеющихся листов без изменения пикселей.
Отдельные маленькие WebP доступны по хешированным адресам. Фоновая очередь
не более двух загрузок: только оружия следующего набора. Видимые предметы
меню/арсенала/снаряжения запрашиваются по факту показа. Загруженные иконки
переиспользуются через blob URL даже при серверном no-store.
Бой/выбор не ждут сеть; при ошибке сохраняется подпись и повтор возможен.
Общие атласы боевых эффектов остаются общими; это не загрузка отдельных
иконок всего арсенала.

UI/типографика/сцены не меняются. Проверки: соответствие плана будущему
выбору, save/reload, независимость от кадров/боевого RNG/сети, сундуки,
лимиты/редкости/слияния, реальные запросы/декодирование/ошибка в браузере.
