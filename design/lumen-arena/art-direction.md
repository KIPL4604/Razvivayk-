# Кратер роя · оригинальные растровые ресурсы

Все семь исходных листов созданы встроенным `image_gen` для этого этапа
23.10.2026. Исходные PNG сохранены без перекодирования в `sources/`;
`source-provenance.json` связывает их с результатами генерации. В manifest
хранятся SHA-256 и размер каждого исходника и runtime-ресурса. Чужих спрайтов
или лицензионных пакетов в этом наборе нет.

Сохраняется принятый язык Люмена: читаемые отдельные пиксели, нижняя центральная
опора, тёмный контур, тёплые каменные акценты и небольшой общий цветовой набор
внутри каждого актора. Размер спрайта босса96px оставляет детали панциря и
клыков; клещ48px должен читаться маленьким силуэтом по краю арены.

| Ресурс | Контракт | Образ |
| --- | --- | --- |
| boss-carapace | 6×5 кадров96px, опора48/90 | Янтарный тяжёлый панцирь и короткие ударные клешни |
| boss-tempest | 6×5 кадров96px, опора48/90 | Синий крылатый дозорный, дуги электричества |
| boss-matriarch | 6×5 кадров96px, опора48/90 | Красный брюшной панцирь, светлые клыки, низкая посадка |
| arena-tick | 6×5 кадров48px, опора24/45 | Коричневый клещ с игольчатыми ногами |
| mega-chest | 6 кадров96px, опора48/90 | Большой деревянный сундук, латунь, зелёные камни, золото |
| crater-tiles | 4 клетки32px | Пепельные плиты, тонкие янтарные трещины |
| crater-props | 4 клетки64px | Каменный маяк, рёбра, корень с кристаллами, обломок |
| arena-fx | 6×5 кадров64px | Огонь/дым, лёд, разряд, пыль/металл, пустота |

У акторов строки идут idle/walk/attack/hurt/death. У FX каждая строка — один
эффект от источника к расширению и рассеиванию. Взрыв сохраняет масштаб между
кадрами: ранняя вспышка мала, пик большой, остатки разлетаются. Фонтан монет
в сундуке дополняет движущиеся presentation-монеты renderer; PNG не начисляет
игровую валюту.

Нормализация выполнена прежним офлайн-процессом: единый масштаб актора,
nearest-neighbor,32цвета/актор, жёсткая alpha, общая нижняя опора. Для сундука
единый масштаб всех шести кадров сохраняет размер основания при открытии.
Клетки пола взяты из внутренних частей четырёх плит, без прозрачного края.
Новые ресурсы подключены к полному builder, старые runtime-PNG не заменяются
при отдельном построении набора:

```powershell
python design/lumen-arena/build_assets.py
python tests/test_lumen_art.py
```

Лично просмотрены roster, все анимационные листы, сундук, окружение и30FX-кадров.
Автопроверки контролируют все28акторов/840кадров, палитру/alpha/опоры,
непустые различающиеся клетки, размеры атласов и SHA исходников. Браузерная
приёмка и ограничения устройства фиксируются основным отчётом этапа.
