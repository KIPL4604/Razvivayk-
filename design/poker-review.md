# Математический покер · проверка 18.10.2026

## Реализованное поведение

Самостоятельный режим No Limit Texas Hold’em один на один, с виртуальными
фишками: серверный бот или два проверенных пользователя Telegram по коду
комнаты. Собственная векторная колода 52 карт, зеркальные K/Q/J, рубашка,
раздача, 3D-раскрытие и движение фишек. Стиль светлой Развивайки сохранён;
зелёное сукно относится только к столу. Новых runtime-зависимостей нет.

SQLite хранит состояние стола. API выдаёт каждому только его закрытые карты,
при пасе рука соперника не раскрывается. Подсказка и бот используют только свои
и общие карты. Equity оценивается против случайной неизвестной руки, 400
симуляций для подсказки; EV колла не учитывает будущие ставки и диапазон
соперника. Текст объясняет, когда колл/пас выгоднее по этой модели.

## Ограничения

Это heads-up, строго два игрока, без покупок/вывода/денежных ставок и XP
кампаний. Бот учебный, без заявления о силе GTO. Обновления идут HTTP polling
примерно раз в 1.5 секунды. Сервер один с общей SQLite; масштабирование на
несколько независимых машин в этой задаче не реализовано. Комнаты истекают
через 72 часа после последнего изменения. Потеря guest-токена лишает доступа
к unsigned solo; вход Telegram позволяет восстановить свой подписанный стол.

Физический телефон и настоящий Telegram WebView/два реальных Telegram аккаунта,
VoiceOver/TalkBack и системный крупный шрифт не проверялись. Telegram-контекст
в двух браузерах имитирован; проверка серверной подписи и игрового состояния
была настоящей. Общий performance benchmark не проводился.
