# Шахматы против компьютера

Отдельная игра в существующей светлой игротеке. Десять кампаний головоломок, их XP и API сохраняются. Шахматы — свободная партия против шести соперников, а не сто фиктивных одинаковых этапов. Данные шахматной партии и локальная статистика сохраняются в существующем хранилище устройства, разделённом по Telegram-пользователю.

Выбор: крупный заголовок, шесть радиовариантов с названиями и короткими описаниями, три цвета (белые/чёрные/случайно), заметная кнопка запуска. По умолчанию «Легко · Любитель», белые. Продолжение не заменяет незавершённую партию новыми настройками; новый старт запрашивает подтверждение замены.

Соперники: Начальный · Новичок; Легко · Любитель; Средне · Клубный игрок; Сложно · Эксперт; Очень сложно · Мастер; Ультрасложно · Гроссмейстер. Звания — игровые названия режимов, не обещание измеренного рейтинга Elo. Для новичка добавляются намеренные случайные легальные ходы; остальные уровни различаются Skill Level, глубиной и временем расчёта Stockfish.

Доска занимает основное место; координаты, оригинальные SVG-фигуры, последний ход, выбор и допустимые цели различимы. Управление двумя нажатиями и с клавиатуры. Доступны отмена полного хода, история, переворот доски, правила, новая партия и сдача. Пешка превращается с явным выбором одной из четырёх фигур. Мат, пат, повторение позиции, правило 50 ходов и недостаток материала определяет chess.js.

Движок Stockfish.js 19.0.1 lite-single работает лениво в Web Worker (~1.9 MB вместе с WASM), без React и новых серверных сервисов. Правила: chess.js 1.4.0. При уходе со страницы поиск останавливается; устаревший ответ не должен менять партию. При ошибке загрузки предлагается повтор с сохранением доски. Используются локальные файлы, внешняя CDN при игре не нужна.

MCP: Context7 для API chess.js; Astryx RadioList — доступный выбор с подписями. Применены скиллы brain-game-interface-design и подготовительный разбор brainstorming; отдельный запрос утверждения не добавляется, поскольку инструкции пользователя требуют непосредственного выполнения инженерных задач и сохранения уже выбранного дизайна.

Проверка: две визуальные итерации на 375/768/1440/1920, реальные ходы движка и восстановление партии в отдельном браузерном профиле. Автоматизированные тестовые наборы без запроса пользователя не добавляются и не запускаются.
