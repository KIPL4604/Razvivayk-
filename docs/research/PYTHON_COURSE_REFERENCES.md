# Курсы Python на GitHub для «Питон-станции»

Дата среза: 22.11.2026. Сравнение по открытым исходникам, опубликованным урокам и условиям лицензий. Число звёзд получено из GitHub API, у freeCodeCamp оно относится ко всему репозиторию.

## Вывод

Наиболее близкие к нашей задаче примеры дают три источника. Helsinki MOOC показывает, как чередовать объяснение, решение и отладку. freeCodeCamp показывает, как разбивать одну мини-программу на последовательные короткие шаги. Exercism показывает, как оценивать поведение программы на разных входах и объяснять, какой случай ученик пропустил.

Из семи рассмотренных репозиториев наиболее практичный кандидат для переиспользования конкретных упражнений и тестов — Exercism Python. Для него подтверждена MIT. Готовые задания уровня функций подходят после появления соответствующего навыка и поддержки в учебной консоли. Действующая [тема «Переменные»](../../design/python-learning-game/learning-flow.md) уже проверяет значение переменной и вывод на нескольких наборах входных данных. Следующую тему можно выстроить по найденным учебным приёмам, продолжая этот формат.

## Как может выглядеть следующий блок

1. **Число и текст.** Сравнить, что получится из 12 и из текста «12» при работе с их значениями. Прочитать и предсказать результат коротких фрагментов.
2. **Преобразование показания.** Датчик даёт значение строкой. Преобразовать его, сохранить в переменной и вывести. Запустить на нескольких разных входах.
3. **Сверка груза.** Получить два строковых показания, вычислить общее число и передать его на табло. Проверить и сохранённый итог, и вывод. Присваивание и вывод возвращаются как часть задачи.
4. **Исправление сообщения.** Починить программу, которая складывает текстовые данные вместо чисел. Вынести этот навык дальше в главу про сравнения и условия.

Это предложенный порядок. В текущей учебной консоли доступны целые числа, строки, переменные, `print()` и базовая арифметика. В готовых заданиях кандидатов встречаются `input()`, преобразования, дробные числа, вызов `print()` с несколькими аргументами и `def`. Эти возможности требуют отдельного решения при реализации.
